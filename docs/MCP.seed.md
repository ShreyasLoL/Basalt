1. **Verified Figma MCP Capabilities (`MCP.md`)**:
* The official Figma MCP Server (<https://developers.figma.com/docs/figma-mcp-server>) exposes design context (`get-file-info`, `get-nodes`, `get-components`, `get-styles`, variable tokens, and layout hierarchy) over `stdio` or `sse` using `FIGMA_API_TOKEN`.

* **What it CAN do**: Allow Codex/Cursor/Claude to inspect frame layouts, spacing tokens, typography scales, and component variants to generate matching React + Tailwind components.

* **What it CANNOT do autonomously**: It does not automatically run visual pixel-diff regression tests inside a headless browser without a companion Playwright/browser screenshot tool, nor does it bypass Figma account permissions. Thus, BASALT defines all design tokens explicitly in `FRONTEND.md` and `tailwind.config.ts` so the UI builds deterministically even when offline.

2. **BASALT MCP Server (`mcp/`)**:
* Exposes a local JSON-RPC 2.0 MCP server separating **9 Read-Only Inspection Tools** (`get_system_health`, `get_market_watch`, `get_instrument_snapshot`, `get_order_book`, `get_recent_trades`, `get_paper_positions`, `get_portfolio_summary`, `get_strategy_status`, `inspect_feed_health`) from **5 Guarded Simulation Tools** (`run_backtest`, `run_replay`, `run_test_suite`, `run_benchmark`, `trigger_kill_switch`) with strict JSON schema validation, rate limiting (`5 calls/min` on benchmark/backtest tools), audit logging to `logs/mcp_audit.jsonl`, and zero shell or secret access.
