**Provider Selection Decision**:

1. **Primary Offline/CI Default**: `DeterministicSyntheticProvider` + `CsvJsonReplayProvider` so BASALT runs 100% offline in university demos, interviews, and automated tests without requiring active broker credentials.

2. **Primary Live Indian Market-Data Adapter**: **Upstox API v2** (free real-time WebSocket + historical candles, high 50 req/sec standard rate limit) and **FYERS API v3** (free real-time WebSocket + 5yr daily / 1yr intraday history, no static IP needed for market-data endpoints).

3. **Secondary Adapter**: **DhanHQ v2** for users who subscribe to the ₹499/mo Data API and want 20-level market depth on NSE equities/F&O.
